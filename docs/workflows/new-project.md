# New Project Workflow

Use this workflow when starting or refreshing a serious KentOS AI project slice.

1. Define product intent and user roles.
2. Confirm project lane and stack.
3. Create or update `AGENTS.md`, `README.md`, `DESIGN.md`, `.interface-design/system.md` if relevant.
4. Establish verification commands before implementation.
5. Make the smallest coherent slice.
6. Run the smallest relevant verification.
7. Log risks, assumptions, and next steps.
